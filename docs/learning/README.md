# MiniPay 30 天项目驱动学习记录

本目录是 `codex/minipay-30day-learning` 分支的学习与改造证据。每天按“理论 → 源码 → 实操 → 口述 → 验收”推进；当天验收完成后才进入下一天。

## 使用规则

1. 先回答当天讲义的诊断题，不查资料。
2. 阅读讲义中指定的源码入口；一次最多跟踪三个文件。
3. 完成实操并记录现象，不只记录命令。
4. 口述验收题；答不清的内容进入错题区。
5. 涉及资金、消息、鉴权和数据库的改造必须先写测试，禁止直接修改余额或跨服务访问数据库。
